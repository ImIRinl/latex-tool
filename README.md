# LaTeX 格式面板

一个面向中文论文写作者的 VS Code 扩展。它把常用的 LaTeX 格式做成类似 Word“格式”面板的可视化按钮：先设置一次，写作时点击即可插入到光标位置，不需要记住复杂的 LaTeX 语法。

## 下载与安装

打开本项目的 [Releases](../../releases) 页面，选择最新版本：

- `latex-format-palette.vsix`：在 VS Code 中选择“扩展 → … → 从 VSIX 安装”。
- `latex-format-palette-portable-v2.0.2.zip`：解压后双击 `双击安装.cmd`，适合发给不会技术操作的朋友。

安装后重新打开 VS Code，在左侧活动栏点击“LaTeX 格式面板”图标即可使用。

## 主要功能

- 段落、标题、表格、图片和公式的可视化格式样式。
- 表格样式可提前设置内容、表格名称（表格注释）、位置和字体，插入时只需选择行数和列数。
- 图片样式可预设原图、百分比或像素大小，插入时支持拖入图片或打开文件选择器；插入后可右键修改属性。
- 公式工具支持分数、上下标、根号、积分、求和、矩阵、分段函数等结构，并提供实时预览。
- 一键新建论文、目录、页眉页脚、页码、导航引用、PDF 预览和文档检查修复。
- 设置可导出为 `.latexstyles` 文件，方便在多台设备之间分享。
- 内置中文教程，不要求用户会写代码。

详细操作请阅读 [使用说明.md](使用说明.md)。

## 开发与测试

项目本身不需要联网运行，公式预览资源已随扩展打包。开发者可以在 PowerShell 中运行：

```powershell
node .\extension\test\run-tests.js
.\build.ps1
```

构建结果位于 `dist` 目录。构建脚本会自动读取 `extension/package.json` 中的版本号。
