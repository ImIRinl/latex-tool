LaTeX 格式面板 2.0.2
======================

安装方法
--------
1. 双击“双击安装.cmd”。
2. 安装完成后重新打开 VS Code。
3. 点击 VS Code 左侧的“LaTeX 格式面板”图标。

如果双击安装没有成功
----------------------
1. 打开 VS Code。
2. 点击左侧“扩展”。
3. 点击扩展页面右上角的“…”菜单。
4. 选择“从 VSIX 安装”。
5. 选择“latex-format-palette.vsix”。

使用方法
--------
打开一个 .tex 文件，把光标放在需要插入内容的位置，然后点击格式卡片。
面板右上角的“？教程”可以打开完整图文式说明页面。
“论文方案”可以一次生成协调一致的正文、标题、图片和表格样式。
“PDF 预览”会调用 LaTeX Workshop 编译并显示真实论文。
“导航引用”可以跳转到章节、图片或表格，也可以直接插入图表引用。
“目录”可以插入或更新带页码的论文目录，并可直接更新 PDF 预览。
“页面设置”用于设置页眉、页脚、页码、首页规则和常用论文方案。
“文档工具”可以一键新建完整论文，也可以检查当前 .tex 文件并在预览后修复安全问题。
“公式工具”会打开独立浮动窗口，可以选择分数、根号、积分、求和、矩阵等结构并直接填写内容。
如果没有自动浮动，可点击公式窗口顶部的“独立窗口”，或将标签拖出 VS Code 主窗口。

文档工具
--------
点击侧边栏顶部“文档工具”，可以保存自己的默认新建方案。
标题、作者、日期、单位、专业、指导教师、摘要、关键词和目录都可以通过可视化选项设置。
“一键新建默认文档”会要求选择保存位置，然后生成一个可以直接编译的 .tex 文件。
“检查与修复”只分析当前文件，不检查或修改 MiKTeX。
问题会按错误和提醒列出；点击“转到位置”可以回到对应代码。
安全修复默认选中，其他修复必须主动勾选。所有修复都会先显示前后预览，应用后可按一次 Ctrl+Z 撤销。
可选择“每次保存时自动检查”，也可以点击“解释最近编译错误”查看常见错误的中文说明。

公式工具
--------
公式窗口顶部会显示当前插入目标文件和行号。
在蓝色公式槽位中填写内容，点击分数、上下标、根号等结构可以继续嵌套；按 Tab 切换到下一处。
公式编辑支持撤销和重做，右侧会实时预览公式及编号位置。
公式样式可以设置行内、独立或带编号公式，并设置字号、编号和前后间距。
公式可以保存到“我的公式”，常用符号可以保存到“变量库”并添加单位和说明。
把光标放入已插入公式的代码中，右键“修改当前对象属性”可以重新编辑。

目录与页面设置
------------------
把光标放在目录位置，点击“目录”后通过下拉框设置显示层级、标题样式、页码和点线。
再次使用目录功能会更新原目录，不会重复插入。
页面设置可选普通论文、学位论文或书籍预设，也可逐项自定义。
如果选择“从正文/当前光标处”开始页码，应先把光标放到正文开始位置。
把光标放入由插件生成的目录或页面设置代码中，右键“修改当前对象属性”可重新设置。

段落样式
--------
字体和常用中文字号通过下拉框选择，也可以选择“自定义”。
行距支持单倍、1.5 倍、双倍、多倍、固定值和最小值；段前段后可按行或磅设置。
可分别设置左右缩进、首行缩进和悬挂缩进，并支持两端对齐。

表格样式
--------
在“新建格式”中选择“可视化表格样式”，提前设置表格内容、表头和位置。
表格名称可以单独设置字体、字号、行距、粗体、斜体和是否居中。
写作时点击该样式，再通过方格选择需要的行数和列数。
随后可以像表格软件一样直接填写每个格子的内容、表格名称和引用名称。
插入后把光标放入表格代码并点击右键，可重新编辑内容或样式。

图片样式
--------
在“新建格式”中选择“可视化图片样式”，提前设置缩放比例、位置和图注格式。
点击图片样式后，在窗口中按住 Shift 拖入图片，或点击“打开文件资源管理器”。
图片路径会自动写入，并在图片选择窗口直接填写图片说明和引用名称，不需要进入代码按 Tab 填写。
图片编号可选择自动编号，也可在每次插入时填写 1-1 等自定义编号。
插入后如需调整，把光标放入该图片的 figure 代码块，点击右键并选择“修改图片属性”。
右键属性窗口可以原地修改缩放比例、左右位置、浮动位置、旋转、裁剪和图片编号。

2.0 升级说明
------------
2.0 使用全新的格式数据。旧版保存的个人样式不会自动迁移，已有 .tex 文件不会被主动修改。

分享格式
--------
点击面板顶部“导出”，把生成的 .latexstyles 文件发给朋友；默认文档、目录和页面方案也可以一起携带。
朋友点击“导入”即可使用。

说明
----
扩展不会检测或修改 MiKTeX、TeX Live 与论文编译设置。
插入内容时会按需在论文导言区加入 graphicx、booktabs、float、tocloft 或 fancyhdr 宏包。
