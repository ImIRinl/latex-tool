# LaTeX 格式面板

一个面向论文写作者的可视化 VS Code 扩展。用户可以像使用 Word 格式面板一样创建常用格式，并在写作时点击格式卡片，将相应 LaTeX 代码插入当前光标位置。

## 功能

- Word 式段落设置：多种行距、行/磅段间距、左右与首行/悬挂缩进、两端对齐
- 单独保存表格样式，并分别设置内容、表头、边框和位置
- 点击表格样式后通过 Word 式网格选择行列数
- 单独保存图片样式，预设原图/百分比/像素尺寸、位置和图注排版
- 点击图片样式后拖入图片或通过系统文件选择器选图
- 自动补充图片、三线表和固定浮动位置所需的 LaTeX 宏包
- 一键插入或更新带页码的目录，可视化设置层级、标题、点线和换页
- 独立页面设置，可视化设置页眉、页脚、页码、首页和常用论文预设
- 独立“文档工具”，可一键新建带标题、作者、日期、摘要和目录的完整论文文档
- 默认文档方案可保存、预览、导出并随 `.latexstyles` 格式包分享
- 当前文档可视化检查：按严重程度列出结构、括号、环境、宏包、表格、引用、图片路径和插件对象问题
- 修复前显示修改前后对照，只自动处理安全项目，全部修改可用一次撤销恢复
- 可选保存时自动检查，并可把常见编译日志错误翻译成中文说明
- 目录与页面设置支持右键重新修改，并会更新原设置避免重复
- 独立浮动公式工具，通过可嵌套槽位编辑分数、上下标、根号、积分、求和、矩阵和分段函数
- 公式实时预览，支持行内、独立、自动编号和手动编号
- 可保存公式样式、常用公式和带单位与说明的变量库
- 已插入公式支持右键可视化修改，并支持导航和交叉引用
- 保存、编辑、复制、排序和删除格式
- 图片、表格、公式等自定义 LaTeX 模板
- 选中文字后自动包裹；无选区时插入可填写占位符
- 导入和导出 `.latexstyles` 格式包
- 扩展内置完整使用教程

本扩展不检测或修改 MiKTeX、TeX Live、编译链与论文项目配置；“文档检查”只分析当前 `.tex` 文件的内容。
