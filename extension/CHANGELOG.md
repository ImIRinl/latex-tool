# 更新记录

## 2.0.2

- 修复分段函数误插入上标或下标槽后，整组分段内容缩到右上角的问题
- 已有公式后点击“分段函数”时，默认将分段结构追加到公式右侧，并自动修复已产生的同类错误结构
- 内置 KaTeX 离线排版引擎，实时预览现在能正确显示希腊字母、上下标、矩阵和分段函数
- 自动编号预览改为依据当前文档和光标位置估算，不再固定显示 1-1
- 当“随节/随章编号”的公式位于标题之前时，预览会明确提示编号将以 0 开头

## 2.0.1

- 修复插入表格后光标可能仍停留在表格内部，继续插入图片或公式会导致编译失败的问题
- 段落、图片和表格插入完成后统一把光标移到对象外部，连续插入更符合 Word 的操作习惯
- 文档检查新增“图片或表格相互嵌套”错误提示，可直接定位这类 LaTeX 编译故障
- 调整分节、分章公式的计数顺序，确保第一条自动编号也使用正确格式

## 2.0.0

- 采用全新的 2.0 格式数据，不读取旧版个人样式，减少兼容分支带来的故障
- 段落设置升级为 Word 式行距、段前段后“行/磅”、左右缩进、首行/悬挂缩进和两端对齐
- 页面设置新增纸张方向、四边页距、装订线、镜像页边距、分栏、页眉页脚双距离、首页与奇偶页
- 目录支持分别设置一至三级的字号、缩进和行距
- 表格编辑新增行列增删、单元格合并/拆分、列宽、垂直对齐、重复表头和跨页选项
- 图片新增选择后缩略图、锁定比例、旋转、裁剪，并扩展右键属性修改
- 公式工具改为可嵌套的可视槽位编辑，支持 Tab 跳转、撤销/重做、分类符号、编号左右位置和编号范围
- 侧边栏工具按“插入、文档、查看、分享与帮助”分组，主要操作按钮固定在窗口底部
- 修改已保存样式后，会同步更新当前打开文档中由该样式插入的受管对象
- 扩充回归检查，覆盖新数据结构、生成代码、Webview 元素和只读 VS Code 上下文启动

## 1.0.1

- 修复 1.0.0 在新版 VS Code 中启动失败、侧边栏一直显示加载动画的问题
- 改为在扩展自身对象之间传递文档工具状态，不再修改 VS Code 提供的只读上下文对象

## 1.0.0

- 新增独立“文档工具”窗口，提供新建文档与检查修复两个页面
- 新增一键新建默认论文和自定义新建，可设置文档类型、标题、作者、日期、单位、专业与指导教师
- 新增标题页实时预览、摘要、关键词、目录、常用宏包及已有页面方案选项
- 默认文档方案可保存、导出为 `.tex`，并可随 `.latexstyles` 格式包跨设备分享
- 新增当前文件静态检查，覆盖文档结构、括号、环境、数学符号、宏包、表格列数、引用、图片路径和插件对象标记
- 新增类似 Word 的问题列表、源码跳转、修复安全等级与修改前后预览
- 安全修复支持一键处理，并以单次编辑应用，方便用一次 `Ctrl+Z` 完整撤销
- 新增可选的保存时自动检查和常见编译日志中文说明
- 检查与修复仅作用于当前 `.tex` 文件，不检测或修改 LaTeX 安装环境

## 0.9.0

- 新增可独立浮动的公式工具窗口，支持跨显示器、缩放和 VS Code 始终置顶
- 公式窗口会锁定并显示插入目标文件和行号
- 新增普通公式、分数、上下标、根号、求和、连乘、积分、极限、矩阵和分段函数结构
- 新增常用数学符号面板、中文填写项与实时公式预览
- 新增行内、独立和带编号公式样式，可设置字号、字形、编号格式、间距和分页
- 公式支持无编号、自动编号或“1-1”等手动编号
- 新增常用公式保存、收藏、搜索和最近使用列表
- 新增变量库，可保存符号、名称、单位、说明和分组，并检查重复符号
- 已插入公式支持右键原位修改，导航面板支持公式跳转和引用
- 格式包可选择一起导出公式样式、常用公式和变量库

## 0.8.0

- 新增一键目录，可设置标题、层级、页码、点线和前后换页
- 已有受管目录会原位更新，并提供“更新并预览”双次编译入口
- 新增独立“页面设置”，可视化设置页眉、页脚、页码、横线和与正文距离
- 页眉页脚支持固定文字、当前章节、当前小节和论文标题
- 页码支持页眉/页脚、左中右/双面外侧、阿拉伯数字/罗马数字及起始页码
- 新增首页相同、首页隐藏和首页单独内容三种模式
- 新增普通论文、学位论文和书籍排版预设，以及页面纸张实时预览
- 目录和页面设置支持右键重新修改、暂停显示、恢复默认和安全删除

## 0.7.0

- 新增可视化表格内容编辑器，可直接填写行列、单元格、表格名称和引用名称
- 已插入表格支持右键修改内容与完整样式，并增加自动列宽和平均分配列宽
- 图片插入窗口直接填写说明文字、编号和引用名称，不再依赖代码占位符
- 由新版插入的段落支持右键重新修改字体、字号、间距、对齐和分页属性
- 新增整篇论文格式方案，一次生成正文、一级标题、二级标题、图片和表格样式
- 新增段前分页、与下一段同页、避免孤行，以及图表前分页控制
- 新增真实 PDF 预览按钮，调用 LaTeX Workshop 编译和显示当前论文
- 新增章节、图片、表格导航面板，并可直接插入图表交叉引用
- 导航面板优先读取 AUX 中的真实编号，未编译时按源码顺序估算

## 0.6.0

- 段落样式新增宋体、黑体、楷体、仿宋和沿用论文设置
- 段前、段后间距改为按行选择，提供 0—3 行常用值
- 段落字号、行距和首行缩进由数字输入改为中文化下拉选项
- 表格内容、表头、表格名称和图片图注统一使用中文字号下拉选项
- 扩充初号至八号的中文字号，并修正六号、小六名称对应关系
- 旧版以 pt 保存的较大段落间距会自动换算为行距

## 0.5.0

- 图片编号支持自动排列，也支持手动输入 `1-1` 等编号
- 图片样式新增编号方式设置，手动编号会在选择图片时提示填写
- 使用教程增加右键修改图片属性说明

- 支持原图大小、百分比缩放和自定义像素宽度，并可预设位置和浮动方式
